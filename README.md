Game-Hub
A modern video game discovery application that lets users search, filter, and explore games by genre and platform. Built with React, TypeScript, and Chakra UI, it offers a responsive and streamlined user experience.

Game-Hub Live Website

Features
Game Search & Discovery: Search for games by title with real-time results.

Genre Filtering: Browse games by 18+ genres, including Action, Adventure, RPG, Strategy, Sports, and more.

Platform Selection: Filter games based on gaming platform.

Sorting & Ordering: Sort results by relevance and additional criteria.

Dark Mode Toggle: Switch between light and dark themes for accessibility and user preference.

Responsive Design: Optimized for both mobile and desktop screens.

Dynamic Page Headings: Headings update based on filters for an improved user experience.

Tech Stack
Framework: React

Language: TypeScript

UI Library: Chakra UI

Deployment: Vercel

Styling: CSS, Chakra UI components
